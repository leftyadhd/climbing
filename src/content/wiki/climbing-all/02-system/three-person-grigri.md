## 3인 1조의 구조

싱글 피치 기준으로 아래 세 역할이 순환한다.

| 역할 | 위치 | 장비 |
|------|------|------|
| **선등자 (Leader)** | 루트를 오름 | 하네스, 퀵드로, 확보줄 |
| **빌레이어 (Belayer)** | 지면에서 선등자 확보 | GriGri + HMS 카라비너 |
| **세컨 (Second)** | 대기 또는 선등자가 상단에서 확보 | 하네스 |

한 번의 등반 사이클에서 역할이 아래처럼 전환된다:

```
[사이클]
A 선등 → B 빌레이 → C 대기
         ↓
A 상단 앵커 → A가 B 빌레이 (상단) → B 등반
         ↓
B 도착 → B가 C 빌레이 (상단) → C 등반
```

---

## 1단계 — 선등 빌레이 (GriGri, 지상)

### 설치

1. GriGri에 로프를 통과시킨다 (클라이머 쪽 로프가 GriGri 아래 구멍으로 나와야 함)
2. HMS 잠금 카라비너로 GriGri를 하네스 확보 루프에 건다
3. 카라비너를 잠근다
4. **파트너 체크**: 클라이머의 매듭과 자신의 설치를 서로 확인

### 자세

- 첫 볼트 직하 방향에서 1.5~2m 후방
- 무릎 살짝 구부림, 클라이머를 시선으로 추적
- 제동 손(비주도손)은 항상 GriGri 아래 로프를 잡는다

### 줄 내보내기 (클리핑 시)

GriGri는 캠이 로프를 붙잡고 있어 자연스럽게 나가지 않는다.

**방법 A — 핸들 살짝 올리기**
1. 주도손으로 핸들을 1~2cm만 들어올린다
2. 비주도손(가이드 손)으로 클라이머 쪽 로프를 앞으로 당긴다
3. 클리핑 완료 후 핸들을 내리고 슬랙을 회수한다

**방법 B — 핀치 방법**
GriGri 아래 로프를 검지와 엄지로 집어 확보기 쪽으로 밀면 캠이 열리며 로프가 나간다. 핸들보다 세밀한 제어가 가능하다.

> **금지**: 핸들을 완전히 열면 로프가 한꺼번에 나와 클라이머가 갑자기 슬랙을 받는다.

### 추락 잡기

캠이 자동 잠금하지만 **제동 손은 절대 놓지 않는다**.

GriGri 추락 잡기에서 가장 흔한 사고는 핸들을 잡은 상태에서 놀라서 손에 힘을 주어 핸들이 열리는 것이다. 핸들이 아닌 **GriGri 본체를 감싸 쥐는** 습관을 들인다.

→ 다이나믹 캐치와 병행: [다이나믹 캐치](/wiki/climbing-all/04-techniques/dynamic-catch/)

### 하강

선등자가 "내려줘" 신호를 보내면:

1. "내려갈게" 확인
2. 주도손으로 핸들을 **조금씩** 연다 — 속도를 클라이머 피드백으로 조절
3. 핸들을 과도하게 열면 로프가 급격히 나가니 항상 두 손이 GriGri를 제어한다
4. 발이 지면에 닿으면 핸들을 닫고 로프를 팽팽히 유지

## 2단계 — 상단 후등 빌레이 (GriGri, 앵커에서)

선등자가 상단 앵커에 도달하면 아래 빌레이어를 GriGri로 상단에서 확보한다.

### 선등자의 전환 절차

```
① 앵커 도착 → 자기 확보 (퀵드로 또는 확보줄)
② "자기 확보 됐어, 안전해"
③ 빌레이어: GriGri를 하네스에서 분리해 로프를 느슨하게
④ 선등자: 로프를 앵커 체인 또는 링에 통과 (리다이렉트)
⑤ GriGri를 하네스 확보 루프에 다시 설치 — 이번엔 당기는 방향으로
⑥ "확보 봤어, 올라와"
```

### GriGri 상단 빌레이 설치

앵커를 통해 리다이렉트된 로프를 GriGri에 넣는다.

```
[선등자 하네스 GriGri]
        ↑
     [앵커 링]  ← 로프가 꺾이는 지점
        ↑
     [빌레이어/세컨] ← 올라오는 사람
```

로프 방향:
- **GriGri 아래(제동 쪽)**: 앵커 링을 통과해 세컨으로 향하는 로프
- **GriGri 위(나오는 쪽)**: 선등자 쪽으로 나오는 짧은 여분

> 방향이 반대면 자동 잠금이 작동하지 않는다. 로프 방향을 설치 전에 반드시 확인한다.

### 줄 당기기

세컨이 올라오는 동안 GriGri로 로프를 당긴다.

1. 제동 손으로 GriGri 아래 로프(세컨 쪽)를 당긴다
2. 당긴 로프가 GriGri 위로 나오면 다른 손으로 회수하거나 발 아래로 쌓는다
3. 세컨이 쉬는 동안 GriGri는 자동으로 잠김 → 잡고 있지 않아도 매달림

### 세컨이 멈추거나 추락 시

GriGri 캠이 자동 잠금. 확보자는 캠이 제대로 잠겼는지 확인 후 잠시 손을 쉴 수 있다.

세컨을 하강시켜야 하면:
1. 한 손으로 GriGri 본체를 단단히 잡는다
2. 다른 손으로 핸들을 조금씩 열어 천천히 내린다
3. 앵커 링 마찰이 있어 속도가 느리다 — 이를 이용해 속도를 조절한다

## 3단계 — 역할 전환 (세컨 도착 후)

세컨이 앵커에 도달하면 다음 사람(지상의 세번째 멤버)을 올리기 위해 역할을 전환한다.

### 전환 절차

```
① 세컨 앵커 도착 → 자기 확보
② "자기 확보 됐어"
③ 선등자: GriGri 잠금 확인 후 잠시 손 뗌 가능
④ 세컨이 선등자의 GriGri를 인수하거나 자신의 GriGri로 교체
⑤ 세컨이 확보 준비: "확보 봤어"
⑥ 선등자: 자기 확보 해제, 하강 준비 또는 휴식
⑦ 지상 세번째 멤버에게: "올라와"
```

### 포인트: GriGri 인수 vs 교체

**인수 (같은 GriGri 사용)**
- 선등자가 GriGri를 풀어 세컨에게 건네거나
- 세컨이 먼저 자기 GriGri를 앵커 방향으로 설치한 뒤 선등자 것을 제거

두 GriGri가 동시에 같은 로프를 잡고 있는 순간이 없도록 한다. 한쪽이 잡은 상태에서 다른 쪽 설치 → 전환 완료 후 제거.

**교체 시 순서**
1. 세컨의 GriGri를 먼저 로프에 설치 (잠금 확인)
2. "내가 잡았어" 신호
3. 선등자의 GriGri를 제거

### 지상 세번째 멤버의 준비

세번째 멤버는 지상에서 대기 중 아래를 해야 한다:
- 로프가 발에 걸리지 않도록 정리
- 자신의 매듭 상태 재확인
- 앵커 연결 상태 눈으로 확인 (위를 올려다보며)
- "준비 됐어" 신호

## 안전 체크리스트

### 선등 빌레이 전
- [ ] GriGri 로프 방향 (클라이머 쪽이 아래 구멍으로 나오는지)
- [ ] 잠금 카라비너 잠김
- [ ] 파트너 매듭 확인 (피겨8, 두 루프 통과)
- [ ] 제동 손이 로프를 잡고 있음

### 상단 전환 전
- [ ] 자기 확보 완료
- [ ] GriGri 로프 방향 (이번엔 당기는 방향)
- [ ] 앵커 링 통과 확인
- [ ] 카라비너 잠김

### 역할 교체 전
- [ ] 인수자의 GriGri 먼저 설치 완료
- [ ] "내가 잡았어" 구두 확인
- [ ] 기존 GriGri 제거
- [ ] 지상 멤버의 준비 확인
