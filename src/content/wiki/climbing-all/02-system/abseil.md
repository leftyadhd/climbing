## 개념

하강(Abseil, Rappel)은 앵커에 걸린 로프를 확보기의 마찰력으로 제어하며 벽을 내려오는 기술이다. 파트너가 빌레이하는 하강(Lowering)과 달리, 하강자가 스스로 속도를 조절한다.

등반에서 하강은 흔한 상황이지만, **통계적으로 사고가 가장 많이 나는 구간**이다. 서두르지 않고 각 단계를 순서대로 확인하는 것이 핵심이다.

---

## 필요 장비

| 장비 | 역할 |
|------|------|
| 확보기 (ATC, 8자 등) | 로프에 마찰을 만들어 속도 제어 |
| HMS 잠금 카라비너 | 확보기를 하네스에 연결 |
| 오토블록 또는 프러지크 코드 | 손을 놓았을 때 자동 잠금 (백업) |
| 작은 잠금 카라비너 | 백업을 레그 루프에 연결 |
| 자기확보줄 | 앵커에서 작업 중 자기 확보 |

---

## 1. 앵커 확인

하강 전 앵커의 상태를 반드시 눈으로 확인한다.

**확인 항목**
- 링·체인·볼트가 손상되지 않았는가
- 연결부가 완전히 닫혀 있는가
- 로프를 걸었을 때 로프가 미끄러질 위험이 없는가

앵커가 의심스러우면 추가 보강(슬링·카라비너)을 한다. 자기 판단이 어려우면 내려가지 않는다.

---

## 2. 로프 세팅

### 싱글 피치 — 로프 두 겹 통과 (리드 하강)

앵커 링(또는 카라비너)에 로프 중간 지점을 통과시킨다.

1. 로프 중간 지점(미드마크)을 찾는다
2. 앵커 링에 통과시킨다 — 두 줄이 아래로 늘어짐
3. 두 끝이 지면에 닿는지 확인 (닿지 않으면 매듭 묶기, 아래 참고)

**로프 끝 매듭**
지면에 닿지 않거나 로프가 짧은 경우, 두 끝에 오버핸드 매듭을 묶는다. 매듭 없이 내려오다 로프 끝을 지나치는 것이 가장 치명적인 실수다.

### 로프 던지기

- 바람이 없으면 아래로 던진다
- 바람이 있으면 두 번에 나눠 던진다 (한꺼번에 엉킴)
- 로프가 걸릴 지형이 있으면 내려가며 풀 계획을 세운다

---

## 3. 확보기 설치 (ATC 기준)

두 줄을 함께 ATC에 통과시킨다.

```
[앵커 링]
   ↓ 로프 두 줄
[ATC] ← 두 줄을 같이 걸기
   |
[HMS 카라비너] — 하네스 확보 루프
```

**설치 방법**
1. 두 줄을 함께 루프를 만들어 ATC 슬롯에 통과시킨다
2. ATC의 와이어를 HMS 카라비너에 함께 건다
3. HMS 카라비너를 잠근다
4. 로프를 양손으로 당겨 ATC가 제대로 걸렸는지 확인

**방향 확인**: 카라비너 게이트가 몸 바깥쪽을 향하고, 잠금이 아래쪽을 향하면 하중에 게이트가 열리지 않는다.

---

## 4. 백업 설치 (오토블록)

오토블록(Auto-block / French Prussik)은 손을 놓았을 때 자동으로 잠겨 추락을 막는다. **항상 설치한다.**

**설치 위치**: 확보기 아래, 레그 루프에 연결

```
[ATC] ← 확보기
  ↓ 로프
[오토블록] ← 프러지크 코드 3~4회 감기
  ↓
[레그 루프 카라비너]
```

**설치 방법**
1. 프러지크 코드(또는 슬링)를 두 줄에 3~4회 감는다
2. 코드 양 끝의 고리를 작은 잠금 카라비너로 연결한다
3. 카라비너를 레그 루프에 건다
4. 잠근다

**사용법**: 하강 중 제동 손으로 오토블록을 아래로 밀면 풀리고, 손을 놓으면 자동 잠금된다.

> 오토블록을 확보 루프(배꼽)에 연결하면 안 된다. 추락 시 몸이 접히면서 오토블록이 풀릴 수 있다. 반드시 레그 루프에.

---

## 5. 자기확보 해제 순서

앵커에서 자기확보를 하고 있다가 하강을 시작하는 순서가 중요하다.

```
① 확보기 설치 완료 → 잠금 확인
② 오토블록 설치 완료 → 잠금 확인
③ 로프 하중 테스트: 몸을 뒤로 기울여 확보기가 로프를 잡는지 확인
④ 이상 없으면 자기확보 해제
⑤ 하강 시작
```

**③의 중요성**: 자기확보를 풀기 전에 반드시 무게를 확보기에 실어본다. 설치 오류는 이 단계에서 발견된다.

## 6. 하강 자세와 속도 조절

### 기본 자세

- **발**: 어깨너비로 벌려 벽에 평행하게 붙인다. 발바닥 전체를 벽에 밀착.
- **다리**: 무릎 살짝 구부림, 스프링처럼 충격 흡수
- **상체**: 벽과 수직에 가깝게. 엉덩이를 뒤로 빼는 느낌
- **시선**: 아래를 향해 발 위치와 지형 확인
- **제동 손**: 확보기 아래 로프를 잡아 속도 조절

```
       ↖ 로프
    [앵커]
      |
   [확보기]
      |
  [하강자] — 상체 뒤로 기울임
  /     \
발       발 — 벽에 밀착
```

### 속도 조절

**느리게**: 제동 손을 몸쪽으로 당겨 로프를 꺾는다 → 마찰 증가  
**빠르게**: 제동 손을 확보기 방향으로 올려 로프를 편다 → 마찰 감소

초보자는 제동 손을 엉덩이 뒤쪽으로 향하게 하면 자연스럽게 마찰이 크다.

### 오버행 통과

오버행(바위가 튀어나온 구간)에서는 발이 벽을 잃는다.

1. 오버행 직전에 속도를 줄인다
2. 천천히 아래로 내려가며 발이 허공에 뜨는 것을 받아들인다
3. 오버행 아래로 내려오면 다시 벽을 발로 찾는다
4. 급격히 당기지 않는다 — 로프에 충격이 가면 앵커에 하중이 집중된다

## 7. 확보기별 특성

### ATC (튜브형)
- 두 줄 모두 통과시키는 것을 잊지 않는다
- 마찰 조절이 직관적
- 빠른 하강 시 로프 과열 가능 (장갑 권장)

### 8자 하강기 (Figure-8)
- 설치가 직관적이고 마찰이 충분
- 단점: 로프 꼬임(kink)이 심하게 생김
- 긴 하강에서는 비효율적

### GriGri로 하강
GriGri는 하강 전용 장비가 아니지만 하강에 사용할 수 있다.

1. 일반 빌레이와 동일하게 설치 (클라이머 쪽 로프가 GriGri 아래로)
2. 핸들을 **조금씩** 열어 로프를 내보낸다
3. 백업(오토블록)을 반드시 설치한다 — GriGri는 하강 중 핸들이 완전히 열릴 위험이 있음
4. 한 줄만 통과하므로 하강 후 로프 회수가 어렵다 — 주로 파트너가 내려줄 때 사용

### 뮌터히치 (비상용)
확보기 없이 HMS 카라비너만으로 하강 가능.

1. 뮌터히치 매듭으로 로프를 HMS에 연결
2. 제동 손으로 속도 조절
3. 로프 꼬임이 심하므로 짧은 구간에서만 권장

## 8. 로프 회수

하강 완료 후 로프를 회수한다.

### 확인

지면에 서서 두 줄 중 어느 쪽을 당겨야 하는지 확인한다.
- 앵커 링에 통과한 로프의 방향을 기억한다 (매듭이 있는 쪽을 당기면 안 됨)
- 작은 당김으로 방향을 먼저 테스트한다

### 당기기

- 한 줄만 당긴다 (잘못된 줄을 당기면 로프가 꼬임)
- 당겨지지 않으면 방향을 바꾼다
- 로프가 앵커에 걸리면 좌우로 흔들며 풀어준다

### 로프 걸림 방지

- 하강 전 로프를 던질 때 지형을 확인
- 튀어나온 바위, 나무, 크랙에 걸릴 수 있는 경로를 피해 던진다
- 걸린 경우: 당기지 말고 좌우로 흔든다 → 그래도 안 되면 다시 올라가야 할 수 있음

## 9. 멀티피치 하강

여러 피치를 연속으로 하강할 때 추가 고려사항.

**중간 앵커에서의 순서**
1. 도착하면 자기확보 먼저
2. 오토블록·확보기 제거
3. 다음 피치 로프 세팅
4. 파트너 합류 대기 (좁은 앵커에서 두 명이 동시에 작업하지 않는다)
5. 파트너 도착 → 자기확보 확인 후 하강 시작

**로프 길이 계산**
하강 피치가 로프 절반보다 길면 중간에 멈춰야 한다. 사전에 앵커 위치를 파악한다.

**야간·비 환경**
- 슬림한 로프는 마찰이 줄어 속도가 빨라진다 — 제동 손에 힘을 더 준다
- 장갑 착용
- 로프 끝 매듭은 선택이 아니라 필수

## 흔한 실수와 대처

| 실수 | 결과 | 예방 |
|------|------|------|
| 로프 끝 매듭 안 묶음 | 로프 끝 지나쳐 추락 | 항상 양 끝 매듭 |
| 확보기에 한 줄만 통과 | 한쪽만 내려가며 앵커 쏠림 | 두 줄 확인 |
| 오토블록 확보 루프에 설치 | 추락 시 오토블록 해제 | 레그 루프에만 |
| 자기확보 먼저 해제 | 확보기 오류 시 추락 | 하중 테스트 후 해제 |
| 잘못된 줄 당겨 회수 | 로프 꼬임, 걸림 | 방향 먼저 테스트 |
| 오토블록 너무 짧게 감음 | 확보기에 닿아 잠금 미작동 | 3~4회, 확보기와 간격 확인 |
