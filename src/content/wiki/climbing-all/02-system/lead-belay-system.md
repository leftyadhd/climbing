## 개요

선등 확보는 클라이머가 위로 올라가는 동안 아래에서 로프를 관리하며 추락 시 멈추는 역할이다. 후등 확보와 달리 **줄을 내보내야** 한다는 점이 핵심적으로 다르다.

## 준비

### 매듭 확인 (파트너 체크)
등반 시작 전 반드시 서로 확인한다.

- **클라이머**: 피겨8 매듭이 하네스 두 루프를 모두 통과했는가? 잠금 카라비너는 잠겼는가?
- **확보자**: 확보기 설치가 올바른가? 잠금 카라비너는 잠겼는가? 제동 손이 로프를 잡고 있는가?

### 확보 자세

```
[클라이머]
    ↑ 로프
[첫 볼트]
    ↓ 로프
[확보자] ← 이 위치
```

- 벽에서 1.5~2m 거리, 첫 볼트보다 약간 뒤쪽
- 무릎을 살짝 구부려 충격에 대비
- 제동 손(비주도손)은 항상 로프 아래를 잡는다

## 줄 내보내기 (Feeding)

클라이머가 볼트를 클리핑하거나 위로 이동할 때 줄을 내보낸다.

**기본 동작 순서 (ATC 기준)**
1. 가이드 손으로 클라이머 쪽 로프를 잡는다
2. 제동 손을 확보기 쪽으로 밀어 로프가 통과하게 한다
3. 클리핑이 끝나면 즉시 슬랙을 회수한다

**GriGri 줄 내보내기**
캠 때문에 자동으로 잠기므로 핸들을 살짝 들어 마찰을 줄여야 한다. 핸들을 완전히 열면 로프가 한꺼번에 풀리므로 주의.

→ 상세 기술: [로프 내보내기](/wiki/climbing-all/04-techniques/rope-feeding/)

## 추락 잡기

### 선등 추락의 특성
볼트 위 2m에서 추락하면 **최소 4m + 로프 늘어남** 만큼 떨어진다 (볼트 아래 2m + 슬랙). 선등 추락은 크다.

### 제동 동작
추락이 시작되는 순간:
1. 제동 손을 **몸쪽으로 강하게 당긴다** (로프를 꺾어 마찰 최대화)
2. GriGri는 캠이 자동 작동 — 그래도 제동 손을 놓지 않는다
3. 몸이 끌리는 방향에 저항하거나 순응해 충격을 흡수한다

→ 다이나믹 캐치: [추락 흡수법](/wiki/climbing-all/04-techniques/dynamic-catch/)

### 추락 후
- 클라이머가 "괜찮아?" 확인
- 클라이머가 다시 오를지, 내려올지 결정
- 다시 오른다면 줄 팽팽하게 유지

## 하강 (Lowering)

클라이머가 "내려줘"를 외치면:

1. "내려갈게" 로 확인
2. 제동 손을 몸쪽으로 유지한 채 천천히 로프를 내보낸다
3. 속도는 클라이머의 "천천히" / "좀 더" 피드백으로 조절
4. 클라이머 발이 지면에 닿으면 멈추고 로프를 팽팽히 유지

**주의**: 하강 중에는 절대 제동 손을 놓지 않는다. 로프가 미끄러져 클라이버가 자유 낙하한다.

## 클라이머가 앵커에 도달했을 때

루트 상단에 체인 또는 링이 있는 경우:

1. 클라이머가 앵커에 퀵드로 또는 어깨 걸기로 자기 확보
2. "자기 확보 했어, 줄 느슨하게"
3. 확보자는 줄을 약간 늘어뜨린다
4. 클라이머가 앵커에 로프를 통과시키거나 하강 준비
5. 최종 하강 확인 후 진행

## 흔한 실수

| 실수 | 결과 | 해결 |
|------|------|------|
| 슬랙이 너무 많음 | 추락 거리 증가, 지면 충돌 위험 | 클리핑 후 즉시 회수 |
| 제동 손을 위로 올림 | 마찰 감소, 로프 미끄러짐 | 제동 손은 항상 아래 |
| 클라이머에게서 눈을 뗌 | 타이밍 놓침 | 클라이머만 바라본다 |
| 확보자가 벽 바로 아래 | 추락한 클라이머에게 충돌 위험 | 1.5~2m 거리 유지 |
