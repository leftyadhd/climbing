## 싱글 피치와의 차이

싱글 피치는 올라가면 끝이지만, 멀티피치는 **앵커를 경유하며 반복**한다. 3인 팀에서는 매 피치마다 역할이 명확해야 혼선이 없다.

핵심 차이:
- 앵커 공간이 좁다 — 동시에 두 명이 작업하기 어려운 경우가 많다
- 소리가 안 들린다 — 구두 확인 대신 **로프 신호**를 사용한다
- 로프 정리가 중요하다 — 엉킨 로프가 다음 피치 출발을 막는다

---

## 기본 역할 분담

| 역할 | 약칭 | 이번 피치 행동 |
|------|------|--------------|
| 선등자 (Leader) | L | 피치를 오른다, 앵커 구축, 세컨1 빌레이 |
| 세컨1 (Second 1) | S1 | L 빌레이, 올라와서 S2 빌레이 |
| 세컨2 (Second 2) | S2 | 대기, 올라온다 |

## 한 피치의 전체 흐름

### ① 출발 전 (하단 앵커)

```
L   : 퀵드로 준비, 매듭 확인, "확보 봐줘"
S1  : GriGri 설치, 파트너 체크, "확보 봤어"
S2  : 자기 확보 유지, 로프 정리, 대기
```

S2는 S1이 빌레이하는 로프 뒤에 **연결된 채로 대기**한다. 로프가 엉키지 않게 S1 발아래 S자로 쌓여있어야 한다.

### ② L 등반 중

```
L   : 볼트 클리핑하며 오른다
S1  : GriGri로 줄 내보내기, 클라이머 주시
S2  : 움직이지 않는다. 로프가 당겨지면 S1에게 알린다
```

### ③ L 앵커 도착

L이 앵커에 닿는 순간부터 소리가 거의 안 들린다. **로프 신호**로 확인한다.

```
L   : 자기 확보 → 로프 팽팽히 당김 (2번) = "자기 확보 됐어"
S1  : 로프 팽팽해짐 감지 → 로프 느슨하게 1번 = "알았어"
L   : GriGri(또는 ATC) 앵커에 설치, 줄 당김 3번 = "올라와"
S1  : 로프 당김 1번 = "알았어, 간다"
```

**로프 신호 표준 (팀 합의 필수)**

| 신호 | 의미 |
|------|------|
| 당김 2번 | 자기 확보 완료 |
| 당김 3번 | 올라와 (확보 봤어) |
| 당김 1번 | 알았어 |
| 연속 당김 | 긴급 — 멈춰 |

> 팀마다 신호가 다를 수 있으므로, 등반 전 반드시 합의한다.

### ④ S1 등반

```
S1  : GriGri 분리, 퀵드로 회수하며 오른다
L   : 앵커에서 GriGri로 S1 빌레이 (줄 당기기)
S2  : 자기 확보 유지. S1 로프가 출발점에서 빠질 때까지 기다린다
```

S1이 출발하면 S2와 연결된 로프가 움직이기 시작한다. S2는 이때 출발 준비를 시작한다.

### ⑤ S1 앵커 도착 — 전환

```
S1  : 자기 확보 → 로프 2번 (자기 확보 완료 신호)
L   : GriGri 잠금 유지
S1  : 자신의 GriGri를 로프에 설치 (S2 빌레이 준비)
S1  : "내가 잡았어" → L의 GriGri 인수 또는 교체
S1  : 로프 3번 (S2에게 "올라와")
```

**교체 순서 (무확보 없애기)**
1. S1이 자신의 GriGri를 같은 로프에 먼저 건다
2. L의 GriGri가 아직 로프를 잡고 있는 상태
3. S1: "내가 잡았어"
4. L의 GriGri 제거

두 GriGri가 동시에 같은 로프를 잡고 있는 순간이 전환의 안전 구간이다.

### ⑥ S2 등반

```
S2  : 로프 신호 감지 → 로프 1번 (알았어)
S2  : 출발 (퀵드로 회수하며 오름)
S1  : 앵커에서 GriGri로 S2 빌레이
L   : 다음 피치 준비 (퀵드로 재정비, 캠 확인)
```

### ⑦ S2 도착 — 피치 완료

```
S2  : 자기 확보
전원 앵커에 모임
다음 피치 L 출발 준비
```

## 앵커에서 로프 정리

올라온 로프를 그냥 두면 다음 피치에서 엉킨다.

**버터플라이 코일 (앵커에서)**
- 발 사이에 로프를 걸치거나 앵커 슬링에 걸어 루프를 만든다
- 루프 크기를 일정하게 유지하며 교대로 쌓는다
- 마지막에 루프를 한 번 꼬아 고정

**쌓는 순서**
- L이 올라오는 로프부터 쌓는다 → S1이 올라올 때 이 로프가 먼저 풀린다
- S1이 쌓는 순서도 동일

> 좁은 앵커에서는 로프를 목에 걸거나 하네스 확보줄에 묶어 관리한다.

---

## 소통이 안 될 때 판단 기준

소리도, 로프 신호도 불명확할 때:

1. **L을 시각적으로 확인**한다 — 움직임이 없으면 앵커에서 작업 중
2. **로프가 당겨지면** L이 확보 중이라는 신호 → 출발 준비
3. **로프가 멈추면** 무언가 기다리는 중 → 당김 1번으로 확인 요청
4. **확인 안 되면 절대 자의로 출발하지 않는다**

## 3인 멀티피치에서 자주 생기는 문제

| 상황 | 원인 | 해결 |
|------|------|------|
| S2 로프가 S1 로프와 꼬임 | 출발 전 정리 미흡 | 출발 전 두 로프 경로 분리 확인 |
| L 앵커 도달 확인 안 됨 | 소음·거리 | 로프 신호 사전 합의 필수 |
| 앵커 공간 부족 | 3명이 동시에 작업 | S1 도착 전 L이 장비 정리 완료 |
| S1이 퀵드로 다 회수 못 함 | 크럭스 구간 | S1이 남긴 퀵드로는 S2가 회수 |
| GriGri 전환 중 혼란 | 역할 미확인 | "내가 잡았어" 구두 확인 의무화 |
