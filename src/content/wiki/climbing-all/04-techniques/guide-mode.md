## 개념

가이드 모드는 ATC-Guide, Reverso, Mega Jul 같은 확보기를 **앵커에 직접 설치**해 후등자를 확보하는 방식이다. 하중이 걸리면 로프가 자동으로 잠겨, 확보자가 따로 잡고 있지 않아도 후등자가 매달린다.

멀티피치의 표준 후등 확보 방식이며, 두 명의 후등자를 동시에 확보할 수도 있다.

## 호환 장비

| 장비 | 가이드 모드 지원 |
|------|----------------|
| Black Diamond ATC-Guide | ✓ |
| Petzl Reverso | ✓ |
| Edelrid Mega Jul | ✓ |
| Mammut Smart | ✓ |
| ATC (일반형) | ✗ |
| GriGri | ✗ (별도 방식) |

장비에 **두 개의 구멍**과 **클립 홀(작은 구멍)**이 있으면 가이드 모드 지원.

## 설치 방법

```
[앵커 마스터 포인트]
        |
   [잠금 카라비너]
        |
   [ATC-Guide] ← 확보기
   ↗         ↘
[후등자 로프] [제동 로프]
```

1. 앵커 마스터 포인트에 **잠금 카라비너**를 건다
2. 로프를 ATC의 슬롯에 통과시킨다 (일반 확보와 같은 방향)
3. ATC 본체의 **클립 홀**을 같은 카라비너에 건다
4. **로프 방향 확인**: 후등자 방향 로프가 확보기의 개방면을 통해 나와야 한다

**설치 방향이 핵심**이다. 방향이 반대이면 자동 잠금이 작동하지 않는다. 장비마다 화살표나 그림이 있으니 확인한다.

## 작동 원리

후등자가 추락하거나 멈추면 로프에 하중이 걸린다. 이 하중이 확보기 안의 로프를 카라비너 게이트 쪽으로 밀어 마찰이 기하급수적으로 증가 → 자동 잠금.

반대로 제동 로프를 당기면 이 각도가 깨지면서 잠금이 풀린다.

## 줄 당기기 (후등자 올라올 때)

가이드 모드에서 줄 당기기는 일반 확보보다 **저항이 크다**. 자동 잠금이 되어있기 때문이다.

**방법**
1. 제동 로프를 **앵커 반대 방향**으로 당긴다 (자동 잠금 각도를 깸)
2. 후등자 방향 로프를 동시에 당긴다
3. 반복

익숙하지 않으면 무겁게 느껴진다. 당기는 각도를 바꿔가며 가장 가벼운 위치를 찾는다.

## 잠금 해제 — 후등자를 내려야 할 때

하중이 걸린 상태에서 로프를 풀려면 특별한 절차가 필요하다. **이것이 가이드 모드에서 가장 중요한 기술**이다.

### 카라비너 방법 (Carabiner Trick)
1. 별도의 **잠금 카라비너**를 제동 로프와 앵커에 동시에 건다
2. 이 카라비너를 레버처럼 사용해 제동 로프를 **앵커 방향으로 민다**
3. 자동 잠금 각도가 깨지면서 로프가 풀린다
4. 천천히 하강시킨다

**주의**: 갑자기 힘이 풀릴 수 있으므로 항상 후등자에게 "내려간다"고 먼저 알린다.

### 확보 방식 전환 후 하강
하중이 너무 강하면 카라비너 방법도 어렵다. 이 경우:
1. 제동 로프를 뮌터히치로 앵커에 묶어 임시 고정
2. ATC-Guide를 분리하고 일반 하강 확보로 전환
3. 뮌터히치를 풀며 하강

## 두 명 동시 확보

ATC-Guide, Reverso는 슬롯이 두 개라 두 로프를 동시에 설치할 수 있다. 자동 잠금이 각각 독립적으로 작동해 한 명이 쉬어도 다른 한 명을 올릴 수 있다.

줄 당기기는 두 로프를 동시에 당기거나 교대로 당긴다.

## 흔한 실수

| 실수 | 결과 | 해결 |
|------|------|------|
| 설치 방향 반대 | 자동 잠금 미작동 | 장비 화살표 확인 필수 |
| 클립 홀을 앵커에 안 검 | 하중 시 확보기 이탈 | 클립 홀은 반드시 앵커 카라비너에 |
| 잠금 해제를 모름 | 후등자를 내릴 수 없음 | 카라비너 방법 반드시 숙지 |
| 줄 당기기 방향이 틀림 | 잠금이 더 강해져 당길 수 없음 | 제동 로프를 앵커 반대 방향으로 |
