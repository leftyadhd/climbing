## 개념

추락이 일어날 때 확보자가 딱딱하게 버티면 로프에 충격이 집중된다. 다이나믹 캐치는 확보자가 **추락 방향으로 몸을 이동**해 로프를 조금 더 내주면서 피크 충격력을 낮추는 기술이다.

물리적으로 설명하면: 같은 힘이라도 거리(이동량)가 늘어나면 충격력이 줄어든다(충격량 = 힘 × 시간).

## 왜 필요한가

고정 캐치(확보자가 움직이지 않음)와 비교:

| | 고정 캐치 | 다이나믹 캐치 |
|--|---------|-------------|
| 클라이머에 가는 힘 | 크다 | 작다 |
| 보호물(볼트·캠)에 가는 힘 | 크다 | 작다 |
| 클라이머 느낌 | 급격히 멈춤 | 부드럽게 감속 |
| 추락 거리 | 짧다 | 약간 더 길다 |

## 동작

1. 클라이머가 추락하는 순간을 감지한다 (소리, 로프 갑자기 당겨짐)
2. 제동 손으로 로프를 잡으면서 **벽 방향으로 한 걸음 내딛거나 점프**한다
3. 몸이 앞으로 이동한 만큼 로프가 약간 더 나간다 — 이 여유가 충격을 흡수한다
4. 몸이 멈추는 지점에서 로프도 멈추고 클라이머가 잡힌다

**핵심**: 이동하는 동안에도 제동 손은 로프를 놓지 않는다.

## 언제 쓰지 않는가

다이나믹 캐치는 추락 거리를 약간 늘린다. 아래 상황에서는 쓰지 않는다:

- **지면이 가깝다**: 클라이머가 바닥에 닿을 수 있음
- **바위 턱이 바로 아래에 있다**: 추락 거리 증가 = 레지 충돌 위험
- **첫 볼트 아래**: 그라운드폴 위험
- **후등 확보**: 추락 거리가 이미 짧으므로 불필요

## 연습 방법

파트너와 합의 후 낮은 볼트에서 의도적으로 추락해보는 것이 가장 좋다.

1. 클라이머가 "추락!"을 외치고 손을 놓는다
2. 확보자는 미리 예측해 동작을 준비
3. 반복하면서 타이밍과 이동 거리를 익힌다

처음에는 작게(반 걸음), 익숙해지면 풀 스텝으로 키운다.

## GriGri 사용 시

GriGri는 캠이 자동으로 잠기므로 확보자가 크게 움직이지 않아도 된다. 그러나:

- 캠이 잠기는 순간 고정 캐치와 동일한 충격이 발생할 수 있음
- GriGri로도 다이나믹 캐치를 할 수 있다 — 핸들을 살짝 열어 약간의 로프를 내준 뒤 닫는다
- 초보 확보자에게는 권장하지 않음 (핸들 조작이 순간적으로 어려움)

## 흔한 실수

- **너무 많이 이동**: 과도한 슬랙이 생겨 추락 거리가 위험할 만큼 늘어남
- **제동 손을 위로 올림**: 마찰이 줄어 로프가 미끄러짐 — 이동하는 동안에도 제동 손은 항상 아래
- **타이밍이 늦음**: 추락이 다 끝난 뒤 움직이면 의미 없음
